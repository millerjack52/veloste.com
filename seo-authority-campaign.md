## Priority order

### 1. Client attribution and case-study links

Cost: free  
Expected value: highest  
Required input: approval from a real client

Ask each client whose website Veloste actually designed or developed to add a
plain attribution on an appropriate page. The attribution must describe real
work and should never be forced into a site-wide footer if the client does not
want it.

Preferred example:

> Website strategy, design and development by
> [Veloste](https://www.veloste.com/web-developer-calgary/).

For The Juniper Hotel & Bistro, the better destination is the project evidence:

> Read the
> [Juniper Hotel website case study](https://www.veloste.com/case-studies/juniper-hotel/)
> by Veloste.

Client request:

> Subject: Small attribution request for the website project
>
> Hi [Name] — I have published a factual case study of the website work at
> [case-study URL]. Would you be comfortable linking to it from an appropriate
> page on your site? A simple line such as “Website strategy, design and
> development by Veloste” is enough. I will only publish claims, outcomes, or a
> testimonial that you approve. No problem if you would rather not add it.

Evidence to request at the same time:

- Permission to identify the client and project publicly.
- One named testimonial in the client’s own words.
- Any result the client can verify, including the measurement period and data
  source.
- Permission to link to the live work.

## Measurement cadence

Weekly:

- Check whether the Calgary page, case study, and website brief are indexed.
- Record exact-query position from the same location/device methodology.
- Record impressions, clicks, CTR, and average position for the Calgary page.
- Record new referring domains and referral visits.

Monthly:

- Compare branded and non-branded impressions.
- Review which external profiles and links Google reports.
- Improve snippets only after the page has impressions.
- Expand proof only when a client can verify it.

Do not react to daily rank movement. Change strategy when several weeks of
Search Console and referring-domain evidence show a stable pattern.
